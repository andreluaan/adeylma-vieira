# Adeylma Vieira | Moda & Lingerie

Identidade visual da revendedora Adeylma Vieira (D'Luck, Del Rayssa Lingerie e La Paola Lingerie), com duas versões de cor: preta e bege.

- `index.html`: página da marca, com troca de tema entre preto e bege
- `styles.css`: cores dos dois temas e estilos dos componentes
- `components.js`: cartão, perfil do Instagram e textos de WhatsApp
- `pdf/`: páginas usadas para gerar os PDFs
- `arquivos/`: PDFs prontos (apresentação e cartões para a gráfica)

## Gerar os PDFs de novo

```powershell
.\gerar-pdfs.ps1
```

Usa o Microsoft Edge instalado no Windows e salva tudo em `arquivos/`.
